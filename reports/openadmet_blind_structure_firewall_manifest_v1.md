# OpenADMET sealed blind-structure firewall manifest v1

This preregistration binds the sealed executor to the official 750-row
structure-only table, its SHA-256 digest, exact ordered schema and the parent
data manifest. A hash, schema, row-count or label-column mismatch must fail
closed.

The blind structures have two permitted uses: record-level removal of external
data that has the same standardized molecular identity or Morgan radius-2/2048
Tanimoto similarity at least 0.90, and final inference from a frozen recipe.
The similarity threshold is fixed before an external source is audited.

Removal counts cannot accept, reject or rank a source and cannot select a model,
architecture, hyperparameter, loss weight or ensemble. The planner may receive
only aggregate removal counts, the filtered external-table hash and the false
test-label-access flag. It must never receive raw blind structures, per-record
neighbors or blind-set distribution summaries.

The standardizer implementation hash remains explicitly pending until the v1
source-bound control suite closes and EC-VOI v2 source is frozen. Therefore this
manifest is a preregistration, not yet evidence that the firewall run passed.

Machine-readable contract:
`reports/openadmet_blind_structure_firewall_manifest_v1.json`.
