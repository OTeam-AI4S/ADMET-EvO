# Supplementary Tables S1–S4 for the ADMET-EvO v2.7 Methods

> **Internal audit version.** This expanded evidence table is retained for traceability. The concise submission version is `admet_evo_supplementary_methods_v27_compact.md`.

These tables report the implemented v2.7 diagnostic definitions and the protocol settings present in the frozen code and result artefacts. ADMET-EvO v2.7 denotes the frozen system and endpoint-specific model mapping. Evidence Packet v5 and v5.4 denote successive Data-axis evaluation protocols; they are not software-version labels.

## Table S1 | Implemented definitions and operating parameters of HardnessCard-v1

Let \(\operatorname{clip}_{01}(x)=\min[1,\max(0,x)]\). Molecules were converted to largest-fragment canonical isomeric SMILES. Scaffolds were chirality-aware Bemis–Murcko scaffolds, and molecular similarities used 2,048-bit radius-2 Morgan fingerprints with the Tanimoto coefficient. The default sampling limit was \(L=2{,}000\); a requested limit below 100 raised an error.

| Component | Implemented severity \(h_k\) | Weight \(w_k\) | Sampling limits and fixed parameters | Stored confidence \(c_k\) | Serialized card-level recommendation |
|---|---|---:|---|---|---|
| Data scarcity (`scarcity`) | Let \(S=\max(1,\lvert G_{\mathrm{tr}}\rvert)\), where \(G_{\mathrm{tr}}\) is the set of unique non-null training-scaffold strings. \(h_{\mathrm{scar}}=\operatorname{clip}_{01}\left[1-\ln(1+S)/\ln(3001)\right]\). | 0.18 | Full training set; reference scaffold count = 3,000. Training-row count is retained as evidence but does not enter the severity. | 1.0 | If \(h_{\mathrm{scar}}\ge0.45\): `data:assay_aligned_external_or_transfer`. |
| Class imbalance (`imbalance`) | Classification: for the finite training labels, \(p=\operatorname{mean}(y)\), with \(p=0.5\) when no finite label exists; \(h_{\mathrm{imb}}=\operatorname{clip}_{01}[1-2\min(p,1-p)]\). Regression: \(h_{\mathrm{imb}}=0\). | 0.12 for classification; 0 for regression | Full training-label vector; binary labels are assumed to be encoded as 0 and 1. | 1.0 for classification; 0 for regression | If \(h_{\mathrm{imb}}\ge0.35\): `model:imbalance_aware`. |
| Chemical-domain shift (`domain_shift`) | Let \(U\) be the row-wise fraction of non-empty validation scaffolds absent from training. For each evaluable sampled validation molecule \(j\), let \(s_j\) be its maximum similarity to a sampled training molecule, \(\bar{s}=m^{-1}\sum_j s_j\), and \(O=m^{-1}\sum_j\mathbf{1}(s_j<0.4)\). Then \(h_{\mathrm{shift}}=\operatorname{clip}_{01}[0.45U+0.35O+0.20(1-\bar{s})]\). If no non-empty validation scaffold exists, \(U=0\); if no fingerprint comparison is evaluable, \(\bar{s}=0\) and \(O=1\). | 0.25 | Training cap \(L\); validation cap \(\min(L,1000)\). Sampling without replacement uses seed \(q\) for training and \(q+1\) for validation. The 10th percentile of \(s_j\) is stored as evidence but does not enter \(h_k\). | \(\min(1,m/200)\), where \(m\) is the number of evaluable sampled validation molecules. | If \(h_{\mathrm{shift}}\ge0.35\): `feature:multi_view_and_pretrained`. |
| Local structure–activity roughness (`local_roughness`) | Let \(D\) be mean nearest-neighbour disagreement over the domain-shift samples. For classification, \(d_j=\mathbf{1}(y_j\ne y_{n(j)})\); for regression, \(d_j=\operatorname{clip}_{01}[\lvert y_j-y_{n(j)}\rvert/(2\sigma_{\mathrm{tr}})]\), and \(D=m^{-1}\sum_j d_j\). If no fingerprint comparison is evaluable, the implementation sets \(D=1\). Let \(C=A/H_c\), where each sampled training molecule contributes its single nearest other neighbour only when similarity is at least 0.75; \(A\) is the number of label mismatches for classification or target differences of at least \(\sigma_{\mathrm{samp}}\) for regression, and \(C=0\) if \(H_c=0\). Then \(h_{\mathrm{rough}}=\operatorname{clip}_{01}(0.60D+0.40C)\). | 0.23 | \(D\) reuses the domain-shift samples. The cliff-analysis cap is \(\min(L,1200)\), with seed \(q+2\). Both roughness standard deviations use population SD (`ddof=0`); an exact-zero SD is replaced by 1. Cliff observations are directed nearest-neighbour records. | \(\min(1,m/200)\), based only on evaluable validation neighbours; the number of high-similarity cliff observations does not change confidence. | If \(h_{\mathrm{rough}}\ge0.25\): `model:local_kernel_or_ensemble`. |
| Data quality (`data_quality`) | Let \(N=\max(1,N_{\mathrm{tr}})\), and let \(I\), \(M\), and \(F\) be the invalid-SMILES, raw-missing-target, and infinite-target counts. Classification: if \(K\) is the number of canonical structures with more than one distinct numeric label, \(h_{\mathrm{qual}}=\operatorname{clip}_{01}[(I+M+F+4K)/N]\). Regression: if \(R=\sum_g(n_g-1)\) is the excess replicate-row count and \(d=\operatorname{median}_g[\operatorname{SD}(y_g)]/\operatorname{SD}(y)\), \(h_{\mathrm{qual}}=\operatorname{clip}_{01}[(I+M+F)/N+(R/N)\min(1,d)]\). | 0.12 | Full training set. Classification conflict multiplier = 4. Regression audit SDs use sample SD (`ddof=1`); a zero global SD is replaced by 1, and \(d=0\) if no repeated-group SD is available. | 1.0 | If \(h_{\mathrm{qual}}\ge0.05\): `data:quality_filtered`. |
| Split-leakage risk (`split_leakage_risk`) | Let \(E=\sum_i\mathbf{1}[c(x_i^{\mathrm{tr}})\in C_{\mathrm{va}}]\), where \(c(\cdot)\) is the canonical identity and \(C_{\mathrm{va}}\) is the set of non-null validation identities. Thus, overlapping training rows, rather than unique identities, are counted. \(h_{\mathrm{leak}}=\operatorname{clip}_{01}[E/\max(1,\min(N_{\mathrm{tr}},N_{\mathrm{va}}))]\). | 0.10 | Full training and validation sets; exact canonical-molecule identity only; no sampling or scaffold/group-overlap term. | 1.0 | If \(h_{\mathrm{leak}}>0\): `data:leakage_safe`. |

The aggregate score was

\[
H=\frac{\sum_k w_k h_k}{\sum_k w_k}.
\]

The weights sum to 1.00 for classification. For regression, the imbalance component is disabled and the remaining weights are renormalized by 0.88. Confidence is diagnostic metadata and does not attenuate \(H\); it is a coverage heuristic rather than a calibrated probability or confidence interval. The three `dominant_factors` are selected by raw severity, not by weighted contribution, and `replicate:multi_seed_lcb` is always appended to the recommendations.

The thresholds above are the recommendations serialized in the card. The executable planner uses lower routing thresholds of 0.03, 0.25, 0.25, 0.20, and 0.35 for data quality, imbalance, domain shift, local roughness, and scarcity, respectively. These values are fixed implementation parameters, not sensitivity-selected estimates; no completed sensitivity analysis of component weights, thresholds, or sampling limits was present in the audited v2.7 artefacts.
